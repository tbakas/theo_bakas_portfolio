Vancouver Crime
Data Analysis

Using data from the Vancouver Police Department, I analyzed what regions of Vancouver tend to see the most crime. I used Python to transform/combine 425,618 data points from 10 years of records. Then I created an interactive Tableau dashboard that visualizes results over geographic location, crime type, and time.

Elbow Statistic
for Unsupervised Learning

By following a research paper, I created a framework for unsupervised learning that estimates the optimal number of clusters for a dataset. The algorithm finds statistically significant elbows in cluster heterogeneity using a null-hypothesis of uniformly distributed data and multiple hypothesis testing methods. It is a rigorous formalization of the popular elbow heuristic.
