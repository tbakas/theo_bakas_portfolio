Vancouver Crime
Exploratory Data Analysis

Using 425 618 data points from the Vancouver Police Department, I analyzed which neighbourhoods of Vancouver have the smallest number of crimes commited. I created a dashboard with Tableau for visualizing the results with many options for filtering. I also plotted the number of crimes vs type of crime, time of day, month and year. And I used Python to combine data for different years and transform variables. The code I wrote can be found here.
